patchy {{ .Chart.AppVersion }} deployed to namespace {{ .Release.Namespace }}
(agent sandbox: {{ .Values.agent.namespace }}).

The CRs are the state machine: findings, investigations, and remediations
live as patchy.bitwisemedia.uk custom resources in {{ .Release.Namespace }}
(kubectl get patchy -n {{ .Release.Namespace }}).

The pipeline idles until two things exist:

  1. An Integration and a Forge custom resource (render them with the
     `integrations:` / `forges:` values arrays, or apply your own). The
     Integration validates webhooks and projects tracking issues; the Forge
     clones and pushes repositories.
  2. The Secrets they reference, created out of band:
       * the forge/provider credential (keys: appID + privateKey, or token,
         plus webhookSecret on Integration secrets) in namespace
         {{ .Release.Namespace }}, named by each CR's spec.secretRef.
       * the model credentials. Claude's lives with the egress broker in
         namespace {{ .Release.Namespace }} ({{ .Values.egressBroker.anthropicSecret }}, key api-key, when the
         provider is anthropic; for bedrock/vertex/foundry-entra the broker
         uses its workload identity instead — annotate
         egressBroker.serviceAccount). The non-brokered runners, whether
         enabled for findings or for evaluations, each need a Secret in
         namespace {{ .Values.agent.namespace }}
         ({{- range $id, $r := .Values.agent.runners }}{{ if and (include "patchy.harnessEnabled" (dict "root" $ "id" $id)) $r.secret }} {{ $r.secret }} (key {{ $r.secretKey }}, as {{ $r.secretEnv }}){{ end }}{{- end }} — none needed when claude is the only harness enabled).
         A non-brokered harness is enabled only when its runner is enabled
         AND its credential exists; claude is enabled by configuration, with
         a missing broker credential surfacing at the broker's /readyz.
         Every allowlisted model needs one enabled harness that supports it,
         or the controllers refuse to start.
     See deploy/kustomize/base/secrets.example.yaml in the patchy repository
     for the exact shapes and kubectl one-liners.
